What Is a QR Code?

A QR Code is a two-dimensional barcode that can store information such as website URLs, text, phone numbers and email addresses. QR codes can be scanned using many modern smartphones and QR scanning applications.

Our free QR Code Generator makes it easy to create a QR code from text or a website URL. You can generate the code and download it as an image for use on websites, documents, posters and other materials.

What Can You Create a QR Code For?

  • Website URLs
  • Plain text
  • Phone numbers
  • Email addresses
  • Contact information
  • Other text-based information
